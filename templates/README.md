# Batoi AIF Starter Templates

These templates are intentionally small copyable entry points. They are not generated at install time.

Use the template closest to the target deployment:

- `standalone/` for Composer-based PHP projects.
- `zip-dropin/` for GitHub ZIP/manual installs.
- `rad/` for Batoi RAD integration bootstrap code.
- `worker/` for queue/worker-style embedding jobs.
- `rag/` for vector search and retrieval-augmented workflows.
- `laravel/` for copying the Laravel example structure into a Laravel app.
- `symfony/` for copying the Symfony example structure into a Symfony app.
